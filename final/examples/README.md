# Sample reports

These reports use the same simulated lunge and recovery viewed from two directions.

| Report | What to look for |
| --- | --- |
| [Side view](side_view.pdf) | The lunge has a complete score and a review cue for torso inclination. |
| [Front view](frontal_view.pdf) | Some measurements remain available, while measures that depend on forward image motion are left unassessed. |

To recreate the samples, run `python tools/generate_examples.py` from the project folder.
